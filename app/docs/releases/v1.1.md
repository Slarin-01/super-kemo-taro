# 言十ベル v1.1

OUCRC 2026 miniハッカソンで制作した、授業の時間割に合わせて通知を自動ミュートするAndroidアプリです。

| 項目 | 内容 |
| --- | --- |
| バージョン | 1.1 |
| versionCode | 2 |
| アプリID | `com.example.super_kemo_taro3` |
| 対応OS | Android 7.0以降（API 24以上） |

## 主な機能

- 岡山大学Moodleと公開シラバス・学年暦から、対象学期の履修情報・教室・授業リンクを取り込み。
- 月〜金・1〜8限の時間割に合わせた通知の自動ミュート。
- 自動ミュートのON／OFF、日曜日までの一時停止、授業終了後の通知動作の選択。
- 今日・次の授業の表示と、Moodle・シラバスへのリンク。
- 次の科目・教室・進行中のメモの有無を確認できるホーム画面ウィジェット。当日の授業終了後は翌日の時間割へ切り替え。
- 教科・期限を設定できるメモと、期限切れメモの一括削除。
- ライト／ダーク表示、テーマカラーの変更。
- READMEにインストール・初期設定・使い方・開発手順を記載。

## インストールと初期設定

対象バージョンのリリースに添付されたAPKを端末へインストールしてください。

1. 起動時に案内される通知制御と、正確なアラームの権限を許可します。
2. 「設定」→「時限カスタム」で授業時刻を確認し、保存します。特に5限は下記の既定値の差を確認してください。
3. 「設定」→「履修を取り込む」から、初回はブラウザで岡大IDにログインして取り込みます。
4. ホームの時間割を確認し、「設定」→「通知設定」で自動ミュートと授業終了後の動作を選びます。
5. 「通知切り替えテスト」で端末の動作を確認します。

## 注意事項

- 履修を取り込むと現在の時間割選択・科目情報を置き換えます。取り込んだ枠は毎週繰り返し、学期の変更や休講は自動反映しません。学期・履修が変わった際は再度取り込み、休講・休暇中は一時停止などで調整してください。
- 自動取り込みは岡山大学向けです。土日・9限以降・曜限が特定できない科目などは時間割に入りません。
- 授業終了時の初期設定では、アプリのお休みモードを解除した後も端末のサイレントを維持します。「通知設定」で変更できます。
- Android 15以降では、本体設定や他のアプリが有効にしたお休みモードは自動解除できません。
- 手動の時間割・時限編集は開発中機能です。5限の既定値は、時限カスタム画面では **13:15〜14:25**、時刻未保存時のホーム表示・アラーム予約では **13:25〜14:15** です。利用前に授業時刻を確認して保存してください。保存後は表示・予約とも保存値を使用します。
