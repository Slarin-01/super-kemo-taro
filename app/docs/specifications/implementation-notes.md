# 現在の注意点

更新日: 2026-10-13  
対象: プロジェクトのappフォルダー

## 金曜日は日曜日で動く

現在はテスト用の設定です。金曜日へ戻すには、TimetableScheduling.ktの曜日一覧でFRIの対応を変更します。既に選んだ枠の予約は、時刻を保存し直すか、枠を解除して選び直すと反映できます。

## 5限の初期値が2種類ある

編集画面は13:15〜14:25、時刻を保存していない場合の予約は13:25〜14:15です。LessonTimeSettings.ktで管理しています。

## 許可がない場合

通知を変更する許可がない場合は、受信時の切り替えと翌週の予約を行いません。時刻予約の許可だけがない場合は、翌週の予約を行いません。

許可を与えて戻った際、通常の全枠予約を自動で作り直す機能はありません。旧受信先の予約を一度だけ移す処理では、許可後の再試行を行います。

## 時刻や端末設定の変更

授業の途中で枠を選んでも、その場で直ちにミュートする処理はありません。開始・終了をそれぞれ次に来る日時で予約します。

端末の時計やタイムゾーンを変更した場合に、自動で予約し直す処理はありません。
