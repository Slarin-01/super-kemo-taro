## 役割

黒、白、ボタン枠の色を名前付きで定義します。

## 変更したいとき

ここに定義した色を変えるときに編集します。Compose画面の配色は共通画面部品の設定も確認します。

## 主な機能

| 部分 | 担当すること |
| --- | --- |
| black / white | 名前付きの黒と白 |
| button_stroke | 通常表示用のボタン枠の色 |

## 扱う情報と結果

色の名前と値を定義します。Compose画面の背景・選択色などは共通画面部品の設定も確認します。
