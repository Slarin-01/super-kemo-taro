## 通知を切り替える時間

時間割には月〜金、1〜8限の40枠があります。選んだ枠の開始時刻にミュートを依頼し、終了時刻に解除を依頼します。

**現在はテスト用に、画面の金曜日を内部では日曜日として動かしています。** この対応はTimetableScheduling.ktにあります。

## 授業の初期時刻

| 時限 | 編集画面の初期時刻 |
| --- | --- |
| 1限 | 08:40〜09:30 |
| 2限 | 09:40〜10:30 |
| 3限 | 10:45〜11:35 |
| 4限 | 11:45〜12:35 |
| 5限 | 13:15〜14:25 |
| 6限 | 14:25〜15:15 |
| 7限 | 15:30〜16:20 |
| 8限 | 16:30〜17:20 |

5限だけは、時刻を一度も保存していない場合の予約が13:25〜14:15です。現在はこの違いを残しています。初期時刻はLessonTimeSettings.ktで管理します。

## 時刻の編集と保存

時間割の枠は、押して選択・解除した時点で保存します。授業時刻の編集とは、保存するタイミングが違います。

開始は終了より前にし、時限どうしが重ならないようにします。間違いがある欄は赤い印で知らせます。

「初期化」は編集内容を初期値に戻します。保存を確認するまでは端末の設定を書き換えません。「保存せず戻る」では編集内容を保存しません。

## 保存するもの

選んだ曜日・時限、授業時刻、一時停止の期限、明るい表示・暗い表示を保存します。以前の予約を作り直したかどうかも記録します。保存を担当するのはAppSettings.ktです。

編集中の入力や開いている確認画面は、画面回転などの後も戻せるようにしています。

## 一時停止と必要な許可

一時停止を有効にすると、直近の日曜日の終わりまで自動切り替えを止めます。日曜日当日はその日の終わりまでです。停止を始めると、許可があればミュートを解除します。

通知変更と正確な時刻予約には、端末側の許可が必要です。許可がなくても選択や時刻は保存できますが、通知変更・予約はできない場合があります。許可画面から戻るだけで、必ず全予約が作り直されるわけではありません。

停止中も予約自体は取り消しません。必要な許可があれば翌週の予約を続けます。一時停止を解除した直後に、その場でミュートし直す処理もありません。

## 画面から戻るとき

時間割編集・通知テストの戻るボタンはメニューへ戻ります。時限カスタムで保存または破棄を確認すると、ホームへ移動します。
