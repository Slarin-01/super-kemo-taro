# 言十ベル 概要仕様書

作成日：2026年10月14日　｜　アプリ版：1.0

## 概要

授業の時間割に合わせて、Android端末の通知を自動でミュート・解除するアプリ。授業中の通知を抑え、毎回手動で切り替える手間を減らす。想定利用者は、定期的な授業を受ける学生。

## 基本仕様

- 対応設定：Android 7.0以降（minSdk 24）。
- 時間割：月〜金の5曜日 × 1〜8限、計40枠。授業時刻は全曜日共通。
- 下部ナビゲーション：ホーム・メモ・設定の3タブ。
- データ保存：選択枠、授業時刻、一時停止期限、表示テーマ、メモを端末内に保存。

## 主な機能と画面

| 画面 | 主な機能 |
| --- | --- |
| ホーム | 時間割の表示と設定への移動。 |
| メモ | 右下の＋からタイトル（任意）と本文を入力して保存。更新日時の新しい順に一覧表示し、タップして再編集。空のメモは保存不可。 |
| 設定メニュー | 日曜日までの一時停止・解除とON／OFF表示。「テーマを編集」、時間割編集、時限カスタム、通知テストへの移動とクレジット表示。 |
| テーマ編集 | ライト／ダーク表示の切替、15色＋カスタムカラーの選択。選択は即時保存し、アプリ全体へ反映。 |
| 時間割編集 | 通知を抑える曜日・時限をタップして選択／解除。選択を即時保存し、開始・終了の予約を登録／取消。 |
| 時限カスタム | 各時限の開始・終了時刻を時計またはキーボードで編集。保存、初期化、変更の破棄に対応。時刻の逆転や時限の重複は保存不可。 |
| 通知切り替えテスト | 通知モードを手動で切り替え、現在の状態を表示。 |

## 基本の利用の流れ

通知制御と正確なアラームの許可 → 授業時刻の設定 → 対象の曜日・時限を選択 → 開始時刻にミュート、終了時刻に通知許可へ切替。設定した枠は毎週繰り返す。

## 動作ルール

- 時刻を保存すると、選択済みの枠を再予約する。端末の再起動・アプリ更新後も、必要な許可があれば予約を復元する。
- 一時停止を有効にすると通知許可へ切り替え、直近の日曜日末まで自動切替を停止する。再操作で解除でき、期限後は自動制御を再開する。
- 許可が不足する場合は端末の設定画面へ案内する。アラームの許可がなくても選択枠・時刻は保存するが、予約は行わない。
- 通知テストのONはミュート、OFFは解除を表す。Android 15以降ではアプリ自身の通知ルールを切り替え、本体設定や他のモードとは分けて状態を表示する。本体側のミュートが残る場合は解除用の設定画面へ案内する。

## 現状の留意点

- テスト用設定により、金曜欄の予約は実際には日曜日に動作する。
- 5限の初期時刻は、編集画面が13:15〜14:25、未保存時の予約が13:25〜14:15で異なる。
