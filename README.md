# 言十ベル

授業の時間割に合わせて、Android端末の通知を自動でミュートするアプリです。岡山大学Moodleから履修情報を取り込み、授業・教室・メモをまとめて確認できます。

制作：スーパーKEMOたろう（OUCRC 2026 miniハッカソン）

| 項目 | 内容 |
| --- | --- |
| バージョン | 1.1（versionCode: 2） |
| 対応OS | Android 7.0以降（API 24以上） |
| アプリID | `com.example.super_kemo_taro3` |
| 時間割 | 月〜金・1〜8限の40枠。授業時刻は全曜日共通 |
| 履修取り込み先 | 岡山大学Moodle・公開シラバス・学年暦 |

[v1.1 リリースノート](docs/releases/v1.1.md)

## 主な機能

- **授業に合わせた通知制御**：授業開始時にミュートし、終了時は選択した通知モードへ切り替えます。自動ミュートのON／OFFと、日曜日末までの一時停止に対応します。
- **履修情報の取り込み**：岡山大学Moodleの履修科目と公開情報から、曜日・時限・教科・教室・Moodle／シラバスへのリンクを取り込みます。
- **ホーム**：時間割、次の授業、曜日別の授業一覧を表示します。授業のリンクを開いたり、教科を指定してメモを作成したりできます。
- **ホーム画面ウィジェット**：「今日の時間割」で次の教科・教室・進行中のメモの有無と、1〜8限の授業を確認できます。当日の授業終了後は翌日の時間割へ切り替わります。
- **メモ**：タイトル・本文・教科・期限を保存できます。「現在進行中」「期限が過ぎたもの」を切り替え、編集・個別削除・期限切れメモの一括削除ができます。
- **表示の変更**：ライト／ダーク表示と、プリセットまたはカスタムのテーマカラーを選べます。

## インストール


APKのインストール時にAndroidから案内された場合は、使用しているブラウザやファイル管理アプリに「不明なアプリのインストール」を許可してください。

## 初期設定

1. アプリを起動し、案内された端末設定で「言十ベル」に通知制御（お休みモードへのアクセス）を許可します。
2. アラームの許可画面が表示された場合は、正確なアラームを許可します。Android 12以降では端末の「アラームとリマインダー」などに設定があります。
3. 「設定」→「時限カスタム」で授業の開始・終了時刻を確認し、必要な時刻に直して「保存して戻る」を押します。この画面は「開発中機能<非推奨の機能>」内にあります。特に5限は未保存時と編集画面の既定値が異なるため、利用前に確認してください。
4. 「設定」→「履修を取り込む」→「取り込む」を押し、初回は外部ブラウザで岡大IDによるログインを進めます。アプリへ戻ると履修情報を取り込みます。
5. 結果の枠数と、ホームの曜日・時限・教科・教室を確認します。取り込むと、現在選択している時間割と科目情報が置き換わります。
6. 「設定」→「通知設定」で、自動ミュートのON／OFFと授業終了後の動作を選びます。
7. 同じ画面の「通知切り替えテスト」で、端末の通知状態が切り替わることを確認します。

通知制御の許可はミュートの切り替えに、アラームの許可は時刻どおりの自動実行に必要です。アラームが許可されていない場合も選択枠や授業時刻は保存されますが、予約は登録されません。許可後に履修の再取り込み、または授業時刻の再保存で予約を登録してください。

## 使い方

### 授業終了後の通知

「設定」→「通知設定」から、次のいずれかを選べます。変更は即時保存されます。

| 設定 | 授業終了時の動作 |
| --- | --- |
| お休みモードのみを解除(通知はミュート)【初期設定】 | アプリのお休みモードを解除し、端末をサイレントにします。通知音・着信音とバイブレーションは鳴りません。 |
| 通知ミュートすべてを解除 | アプリのお休みモードを解除し、端末を通常モードに戻します。音は端末の音量設定に従います。 |

Android 15以降では、アプリ自身のお休みモードを制御します。本体設定や他のアプリが有効にしたモードが残る場合は、「本体の通知モード設定を開く」から確認してください。

### 一時停止と時間割の更新

- 「設定」→「日曜日まで機能を停止」をONにすると、直近の日曜日23:59:59まで自動切り替えを停止します。もう一度操作すると解除できます。停止期限後は、次の予約時刻から自動制御が再開します。
- 履修取り込みは、取り込み時点の年度・学期に該当する科目を対象にします。取り込んだ枠は毎週繰り返し、学期の切り替わりや休講は自動反映しません。履修変更時は再取り込み、休講・休暇中は一時停止などで調整してください。
- 手動でミュート対象の枠を選ぶ場合は、「設定」→「時刻設定」を使います。選択・解除はその場で保存されます。この画面も開発中機能です。

### メモとウィジェット

「メモ」タブの＋ボタンから作成します。タイトル・教科・期限は任意ですが、保存にはタイトルか本文の入力が必要です。メモをタップすると再編集できます。期限を指定すると、期限到達時に「期限が過ぎたもの」へ分類されます。

端末のホーム画面からウィジェット一覧を開き、「言十ベル」の「今日の時間割」を追加できます。ウィジェットの「メモ：あり」は、次の授業の教科に一致する進行中のメモがあることを表します。

## 既知の制約

- 自動取り込みは岡山大学向けです。土日・9限以降・曜限を特定できない科目などは時間割に入りません。取り込み結果に対象外の科目数が表示される場合があります。
- 大学側のページ構成や認証方式が変わると、取り込みが失敗することがあります。接続の有効期限切れが表示された場合は取り込みを開始し直してください。
- 5限の既定時刻には、次の差があります。授業時刻を保存すると、表示と予約の両方で保存値を使用します。

| 5限の既定値 | 開始 | 終了 |
| --- | --- | --- |
| 時限カスタム画面 | 13:15 | 14:25 |
| 時刻を保存していない場合のホーム表示・アラーム予約 | 13:25 | 14:15 |

## データ保存

時間割・授業時刻・通知設定・表示設定・メモ・Moodleのアクセストークンは、端末内のSharedPreferencesへ保存します。Moodleのログインは外部ブラウザで行い、取り込み時はMoodleと大学の公開情報へ通信します。
